🧱 Stack, Queue & Linked List

Sorting and searching both work on arrays — one flat block of memory. But not every problem fits that shape. These three structures show up everywhere once you start writing real programs: undo history, browser tabs, printer jobs, autocomplete chains.

Module 3 · Prerequisite: Module 0 — Foundations (independent of sorting & searching, you can start here any time).

🍽️ Stack not earned

A stack of cafeteria trays: you can only add or remove from the top. Last one in is the first one out — LIFO.

Push a value to add a tray on top. Pop removes whichever tray is currently on top — never one from the middle or bottom.
class Stack:
def __init__(self):
self.items = []
def push(self, value):
self.items.append(value) # add to the end = "top"
def pop(self):
if not self.items: return None # underflow
return self.items.pop() # remove from the end
def peek(self):
return self.items[-1] if self.items else None
class Stack {
private List<Integer> items = new ArrayList<>();
void push(int value) { items.add(value); }
Integer pop() {
if (items.isEmpty()) return null;
return items.remove(items.size() - 1);
}
}

🎟️ Queue not earned

A ticket-counter line: new people join at the rear, but only the person at the front gets served. First one in is the first one out — FIFO.

⬅ Front (served next)Rear (joins here) ➡
Enqueue adds to the rear. Dequeue always removes from the front — whoever has been waiting longest.
from collections import deque
q = deque()
q.append(value) # enqueue: join the rear
front = q.popleft() # dequeue: leave from the front
# deque() is used instead of a plain list because
# removing from the front of a list is O(n); deque does it in O(1)
Queue<String> q = new LinkedList<>();
q.add(value); // enqueue: join the rear
String front = q.poll(); // dequeue: leave from the front

🚃 Linked List not earned

Train carriages linked one to the next. Each node holds a value and a pointer to the next node — there's no single block of memory, just carriages hooked together.

Insert at head hooks a new carriage on at the front and repoints the head. Delete searches carriage by carriage until it finds the value, then relinks around it.
class Node:
def __init__(self, value):
self.value = value
self.next = None # the pointer to the next carriage
def insert_head(head, value):
node = Node(value)
node.next = head # new node points at the old head
return node # it becomes the new head
def delete_value(head, value):
if head is None: return None
if head.value == value: return head.next # skip the head itself
prev = head
while prev.next and prev.next.value != value:
prev = prev.next
if prev.next:
prev.next = prev.next.next # relink around the found node
return head
class Node {
int value; Node next;
Node(int v) { value = v; }
}
Node insertHead(Node head, int value) {
Node n = new Node(value);
n.next = head;
return n;
}

📈 When to use which

OperationArrayStack / Queue (array-backed)Linked List
Access by indexO(1)not allowedO(n)
Insert / remove at one endO(n)*O(1)O(1) at head
Insert / remove in the middleO(n)not allowedO(n) to find + O(1) to relink
Search for a valueO(n)O(n)O(n)

*Removing from the very end of a dynamic array is O(1) amortized — that's exactly what makes it a good fit for a stack. Removing from the front of a plain array is O(n), because everything else has to shift down — which is why queues are usually built on a linked list or a deque instead.
