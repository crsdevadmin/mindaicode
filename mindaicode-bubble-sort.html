👋 New to sorting? Start here (30 seconds)

Sorting just means arranging things in order — smallest to biggest. Computers sort marks lists, prices, names… millions of times a day. Bubble Sort is the simplest way to learn how.

🎓 Real-life example: Imagine students standing in a line for a class photo. The teacher compares two neighbours at a time — if the taller one is on the left, they swap places. She walks the line again and again until nobody needs to swap. That's Bubble Sort. The tallest student "bubbles" to the end first!

💻 The Code

def bubble_sort(arr):
n = len(arr)
for i in range(n):
for j in range(n - i - 1):
if arr[j] > arr[j + 1]:
# swap them!
arr[j], arr[j+1] = arr[j+1], arr[j]
return arr
void bubbleSort(int[] arr) {
int n = arr.length;
for (int i = 0; i < n; i++) {
for (int j = 0; j < n - i - 1; j++) {
if (arr[j] > arr[j+1]) {
// swap them!
int t = arr[j];
arr[j] = arr[j+1];
arr[j+1] = t;
}
}
}
}

📚 How it works

Compare neighbours. If the left ball is bigger, swap them. After each full pass, the biggest remaining ball has "bubbled" to its final spot (it turns green). Repeat until no swaps are needed.
Worst: O(n²) Average: O(n²) Best: O(n) Space: O(1)

⚠️ Common mistakes

Inner loop goes too far. Writing range(n - 1) instead of range(n - i - 1) still works but wastes time; writing range(n) crashes with index-out-of-range on arr[j+1].
Forgetting the temp variable (Java/C). arr[j] = arr[j+1]; arr[j+1] = arr[j]; loses a value! You need int t = arr[j] first. (Python's a, b = b, a avoids this.)
Mixing up i and j. i counts passes; j walks along the line comparing neighbours. Comparing arr[i] with arr[j] is a different (wrong) algorithm.
Comparing without swapping. Try the 🧪 "Remove the swap" experiment to see why the swap line is the heart of the algorithm.
