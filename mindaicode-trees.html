🌳 Trees & Heaps

A tree grows one insert at a time. A Binary Search Tree keeps a strict rule at every node: everything smaller goes left, everything bigger goes right — which is exactly what makes searching it fast. A heap keeps a looser rule (just parent vs. child) but guarantees instant access to the smallest — or largest — item.

Module 5 · Heap Sort already used a max-heap to sort an array — this page treats the heap as its own reusable data structure.

🌲 Binary Search Tree not earned

Every node: left subtree is smaller, right subtree is bigger. That rule alone is what lets search skip half the tree at every step.

def insert(node, value):
if node is None: return {'value': value, 'left': None, 'right': None}
if value < node['value']: node['left'] = insert(node['left'], value)
elif value > node['value']: node['right'] = insert(node['right'], value)
return node
def inorder(node, out):
if not node: return
inorder(node['left'], out)
out.append(node['value']) # visiting between the two subtrees
inorder(node['right'], out) # always yields sorted order!
Node insert(Node node, int value) {
if (node == null) return new Node(value);
if (value < node.value) node.left = insert(node.left, value);
else if (value > node.value) node.right = insert(node.right, value);
return node;
}

⛰️ Min-Heap not earned

A complete binary tree stored flat in an array. The only rule: every parent is smaller than or equal to its children. That's weaker than a BST's rule — but it's exactly enough to guarantee the smallest item is always sitting at index 0.

Array view — parent of index i is ⌊(i-1)/2⌋, children are 2i+1 and 2i+2:

def insert(heap, value):
heap.append(value)
i = len(heap) - 1
while i > 0 and heap[(i-1)//2] > heap[i]:
parent = (i - 1) // 2
heap[i], heap[parent] = heap[parent], heap[i] # bubble up
i = parent
def extract_min(heap):
if not heap: return None
top = heap[0]
heap[0] = heap[-1]; heap.pop()
# then bubble that root value down until the heap property holds again
return top
PriorityQueue<Integer> heap = new PriorityQueue<>(); // min-heap out of the box
heap.add(value); // O(log n) insert
int smallest = heap.poll(); // O(log n) extract-min
