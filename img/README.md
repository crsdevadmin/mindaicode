# Photos for the analogies

Drop files here with these exact names and they appear automatically — no code change:

| file | what it should show |
|---|---|
| `jar.jpg` | a labelled glass jar in a kitchen |
| `post-box.jpg` | a row of apartment post boxes with numbers visible |
| `register.jpg` | a class attendance register, names and ticks visible |
| `vending.jpg` | a vending machine with the slot and tray visible |
| `cinema.jpg` | a row of cinema seats from behind, in the dark |

Roughly square, ideally under 120 KB each.

If a file is missing or fails to load, the drawn SVG stays and the page looks
exactly as it does now. There is never a broken image or a blank space, so it is
safe to add them one at a time.

**Licensing is your responsibility** — use your own photos or something clearly
royalty-free, and keep a note of where each one came from.
